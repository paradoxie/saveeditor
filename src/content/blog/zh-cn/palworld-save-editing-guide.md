## 存档文件位置

### Windows (Steam)
```
%LocalAppData%\Pal\Saved\SaveGames\<SteamID>\
```

### Windows (Xbox/Game Pass)
```
%LocalAppData%\Packages\PocketpairInc.Palworld_<id>\SystemAppData\wgs\
```

### Steam Deck (Proton)
```
~/.steam/steam/steamapps/compatdata/1623730/pfx/drive_c/users/steamuser/AppData/Local/Pal/Saved/SaveGames/
```

### 存档文件结构

在你的存档文件夹中，你会找到：

| 文件 | 描述 |
|------|------|
| `Level.sav` | 世界数据（基地建筑、野生帕鲁等） |
| `Players/<ID>.sav` | 玩家数据（属性、背包） |
| `LocalData.sav` | 本地设置 |

**重要**：要修改玩家数据，请编辑 `Players` 文件夹中的文件。

## 步骤 1：备份存档

在进行任何更改之前，**务必创建备份**：

1. 导航到你的存档文件夹
2. 将整个文件夹复制到安全位置（如桌面）
3. 标注日期（例如 `Palworld_备份_2026年1月`）

## 步骤 2：上传到在线编辑器

1. 打开我们的 [Palworld 存档编辑器](/zh-cn/editor/palworld)（虚幻引擎编辑器）
2. 拖放你的玩家 `.sav` 文件
3. 等待 GVAS 解析器处理二进制数据

## 步骤 3：查找并编辑数据

不同版本/平台的存档字段并不一致。若编辑器显示只读，请停止修改并改用专用工具。

解析完成后，你将看到游戏数据的 JSON 树。以下内容仅在兼容存档中“可能可编辑”：

### 编辑金币
查找名为以下的属性：
- `Money`
- `Gold`
- `Currency`

若这些字段存在，请小步修改并每次进游戏验证。

### 调整帕鲁属性（字段暴露时）
导航到 `CharacterSaveParameterMap` 找到你的帕鲁：
- **等级**：调整帕鲁等级
- **属性**：微调 HP、攻击力、防御值
- **被动技能**：查看/调整被动能力
- **主动技能**：查看/调整主动技能槽位

### 背包字段调整（字段暴露时）
找到 `ItemContainerSaveData` 来修改你的背包：
- 谨慎调整已有条目的 ID 与堆叠数量
- 每次修改后立即进游戏验证

### 玩家字段（字段暴露时）
查找 `PlayerCharacterMakeData`：
- **等级**：你的角色等级
- **HP/耐力**：基础属性
- **科技点数**：谨慎调整进度点数

## 步骤 4：下载并替换

1. 仅当编辑器显示“可编辑兼容模式”时，点击 **下载修改后的存档**。
2. 导航到你的 Palworld 存档文件夹。
3. 在确认备份可用后再替换原始 `.sav` 文件。
4. 若编辑器处于只读模式，请改用 Palworld 专用工具。

## 常见问题

### 这对多人游戏/专用服务器有效吗？

**单人游戏** 和 **合作模式（作为主机）**：是的，可以编辑本地存档。

**专用服务器**：存档存储在服务器端，需要服务器访问权限才能修改。

### 编辑存档会被封号吗？

Palworld 的单人/合作模式没有反作弊系统。但在专用服务器上，管理员可能有禁止作弊的规则。请负责任地使用。

### 如果编辑后存档损坏怎么办？

1. 恢复你的备份（你备份了吧？）
2. 确保只更改了数值，而不是属性类型
3. 不要修改核心结构元素

## 兼容性总结

| 类别 | 兼容存档中的常见可用性 |
|------|--------------------------|
| **金钱** | 通常可调整货币字段 |
| **帕鲁** | 可能暴露部分等级/属性/技能字段 |
| **背包** | 常见可查看，部分结构可编辑 |
| **玩家** | 可能可调整部分成长字段 |
| **基地** | 多为可查看，编辑支持依结构而定 |
| **世界** | 多为高级/只读，建议用专用工具 |

## 安全编辑提示

1. **一次只编辑一项** - 便于排查问题
2. **保持合理数值** - 极端数值可能导致崩溃
3. **不要修改结构数据** - 只更改属性值
4. **立即测试** - 编辑后马上加载存档
