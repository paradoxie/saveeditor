## 🛠️ Guia de Instalação e Correção de GUID

O problema mais comum ao compartilhar saves de Palworld é o erro de GUID (seu personagem não aparece).

### Passo 1: Backup
Faça backup sempre!
*   **Caminho Steam**: `%LocalAppData%\Pal\Saved\SaveGames\<SeuSteamID>\`

### Passo 2: Colocar o Arquivo
Copie o arquivo `Level-50-Legendary.sav` para dentro da pasta do seu mundo.

### Passo 3: Corrigir o Personagem (GUID)
Se o jogo pedir para criar um personagem novo, o ID do save não bate com seu Steam ID.

**Solução: Use nossa ferramenta online**
1.  Abra o [Editor de Save de Palworld](/pt/editor/unreal).
2.  Envie o arquivo baixado.
3.  Use a função de migração ou edite manualmente o PlayerUID.
4.  Baixe o arquivo corrigido e substitua.
