# Compatibility Matrix

This folder documents parser support levels used by SaveEditor Online.

Legend:

- `Stable`: Parse/edit/save supported with round-trip validation.
- `Experimental`: Parse/edit/save available with guardrails; backups required.
- `Read-only`: Parse/view only, no save export.
- `Unsupported`: Format detected but not editable in web build.

See `matrix.md` for the current public matrix.
