## 🛠️ Guía de Instalación y Fix de GUID

El problema más común al compartir saves de Palworld es el error de GUID (tu personaje no aparece o te pide crear uno nuevo).

### Paso 1: Backup
¡Haz una copia de seguridad siempre!
*   **Ruta Steam**: `%LocalAppData%\Pal\Saved\SaveGames\<TuSteamID>\`

### Paso 2: Colocar el Archivo
Copia el archivo `Level-50-Legendary.sav` dentro de la carpeta de tu mundo (la carpeta con caracteres aleatorios).

### Paso 3: Arreglar el Personaje (GUID)
Si el juego te pide crear un personaje nuevo, es porque el ID del save no coincide con tu Steam ID.

**Solución: Usa nuestra herramienta online**
1.  Abre el [Editor de Save de Palworld](/es/editor/unreal).
2.  Sube el archivo descargado.
3.  Usa la función de migración o edita manualmente el PlayerUID para que coincida con el tuyo.
4.  Descarga el archivo corregido y reemplázalo.
