# SEO 技术审核技能

对 Web 项目进行 14 层级的 SEO 技术架构审核，输出标准化评分表格。

## 执行流程

### 1. 确认审核目标

询问用户（如未指定）：
- 审核**在线网站** URL，还是**本地代码项目**？
- 是否为多语言站点？

### 2. 执行审核

根据目标类型，参考 [checklist.md](references/checklist.md) 中的详细检查项进行审核。

**代码项目**：搜索关键文件和配置
```
# 查找相关文件
grep -r "canonical\|hreflang\|og:image\|ld+json" --include="*.astro" --include="*.tsx" --include="*.vue"
```

**在线网站**：使用 curl 和浏览器检查
```bash
curl -s [URL] | grep -E '<title>|canonical|hreflang|ld\+json'
curl -s [URL]/robots.txt
curl -s [URL]/sitemap.xml | head -50
```

### 3. 输出评分表格

> [!IMPORTANT]
> 审核完成后，必须输出以下格式的评分表格。

```markdown
## 🎯 SEO 审核评分总表

| 类别 | 权重 | 得分 | 加权得分 | 主要发现 |
|:---|:---:|:---:|:---:|:---|
| 基础元数据 | 15% | X | X.XX | 简要说明 |
| 国际化 | 15% | X | X.XX | 简要说明 |
| 结构化数据 | 15% | X | X.XX | 简要说明 |
| URL 路由 | 10% | X | X.XX | 简要说明 |
| 爬虫控制 | 10% | X | X.XX | 简要说明 |
| 性能 CWV | 15% | X | X.XX | 简要说明 |
| 可访问性 | 10% | X | X.XX | 简要说明 |
| 内容质量 | 10% | X | X.XX | 简要说明 |
| **总分** | **100%** | - | **XX.XX** | 总体评价 |

评分等级：🟢 90+ 优秀 | 🟡 70-89 良好 | 🟠 50-69 及格 | 🔴 <50 需改进
```

### 4. 详细检查表

对每个层级输出详细状态：

| 检查项 | 状态 | 说明 |
|:---|:---:|:---|
| Title 标签 | ✅/⚠️/❌ | 具体问题 |

状态：✅ 通过 | ⚠️ 警告 | ❌ 需修复

### 5. 改进建议

按优先级输出：

```markdown
## 📝 改进建议

### 🔴 高优先级
1. [问题] - [解决方案]

### 🟡 中优先级
1. [问题] - [解决方案]
```

## 评分标准

| 得分 | 含义 |
|:---:|:---|
| 10 | 完美实现 |
| 8-9 | 良好，有小改进空间 |
| 6-7 | 及格，存在问题 |
| 4-5 | 较差，多个问题 |
| 0-3 | 严重问题或缺失 |
| N/A | 不适用 |
