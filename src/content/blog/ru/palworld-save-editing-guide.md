> **Статус поддержки (февраль 2026):** Этот поток для Palworld в первую очередь рассчитан на **стандартный GVAS**. Если файл контейнеризирован/зашифрован, редактор может перейти в режим только чтения или рекомендовать профильные инструменты.

## Введение в редактирование сохранений Palworld

![Интерфейс редактора сохранений Palworld](/images/blog/palworld-content.webp)

**Palworld** штурмом захватил мир своим уникальным сочетанием сбора монстров, выживания и строительства баз. Как игра на Unreal Engine 5, она использует сложный бинарный формат сохранения **GVAS** (`.sav`), что делает ручное редактирование невозможным без специальных инструментов.

Если вы хотите восстановить прогресс после бага или аккуратно скорректировать развитие персонажа, это руководство покажет совместимый и безопасный сценарий проверки и редактирования.

## Расположение файлов сохранений Palworld

Прежде чем редактировать, нужно найти файлы. Palworld хранит данные по-разному в зависимости от платформы.

### Windows (Steam)
```
%LocalAppData%\Pal\Saved\SaveGames\<ВашSteamID>\<IDМира>\
```

1.  Нажмите `Win + R`.
2.  Введите `%localappdata%` и нажмите Enter.
3.  Перейдите в `Pal` -> `Saved` -> `SaveGames`.
4.  Вы увидите папку с длинным числовым именем (ваш Steam ID). Зайдите в нее.
5.  Вы увидите папку со случайными символами (это ID вашего мира).

### Windows (Xbox / Game Pass)
```
%LocalAppData%\Packages\PocketpairInc.Palworld_ad4psfrxyesvt\SystemAppData\wgs\
```
*Примечание: Сохранения Game Pass имеют зашифрованные имена файлов и их сложнее идентифицировать.*

### Steam Deck (Linux / Proton)
```
/home/deck/.local/share/Steam/steamapps/compatdata/1623730/pfx/drive_c/users/steamuser/AppData/Local/Pal/Saved/SaveGames/
```

### Структура файла сохранения

Внутри папки вашего мира вы найдете несколько ключевых файлов:

| Файл | Содержание |
|---|---|
| `Level.sav` | Самый важный файл. Данные мира, все Палы (пойманные и дикие) и базы. |
| `LevelMeta.sav` | Метаданные о сохранении (версия, дата). |
| `LocalData.sav` | Локальные настройки, такие как туман войны и обучение. |
| `Players/*.sav` | Индивидуальные файлы для каждого игрока (только инвентарь и базовая статистика персонажа). |

## Шаг 1: Сделайте резервную копию

**СТОП!** Не пропускайте этот шаг. Palworld часто обновляется, и файлы сохранений хрупкие.

1.  Скопируйте всю папку `<IDМира>`.
2.  Вставьте ее на рабочий стол или в папку "Бэкапы".

## Шаг 2: Загрузите в онлайн-редактор

Поскольку файлы являются сжатыми бинарными файлами GVAS, вы не можете использовать Блокнот.

1.  Перейдите в наш [Редактор Palworld](/ru/editor/palworld).
2.  Для редактирования **Палов, Баз или Мира**, загрузите `Level.sav`.
3.  Для редактирования **Инвентаря игрока или Очков технологий**, загрузите файл `Players/0000...00001.sav` (для хоста) или соответствующий ID.
4.  Подождите, пока инструмент проанализирует файл (большие файлы `Level.sav` могут занять несколько секунд).

## Шаг 3: Поиск и редактирование данных

Набор доступных полей зависит от версии и типа сохранения. Если редактор показывает режим только чтения, остановите редактирование и перейдите на профильный инструмент.

После загрузки вы увидите древовидную структуру. В совместимых вариантах здесь обычно находятся основные поля:

### Деньги / Золото (если поле доступно)
Золото — это предмет в инвентаре, а не просто число.
1.  В файле Игрока перейдите к `InventoryInfo`.
2.  Найдите предмет со Static ID `Money` или `GoldCoin`.
3.  Измените значение `StackCount` на `999999`.

### Характеристики Палов (в `Level.sav`, если поля доступны)
Это сложно, так как Палы хранятся в огромной карте (Map).
1.  Найдите `CharacterSaveParameterMap`.
2.  Каждая запись — это экземпляр Пала.
3.  Разверните запись, чтобы увидеть:
    *   `Level`: Уровень Пала (макс. 50).
    *   `Exp`: Очки опыта.
    *   `Talent_HP`, `Talent_Melee`, `Talent_Defense`: Значения IV (0-100), определяющие потенциал.
    *   `PassiveSkillList`: Список пассивных навыков (например, `Legend`, `Ferocious`).
    *   `Gender`: `Male` (Мужской) или `Female` (Женский).

### Инвентарь (если структура поддерживается)
1.  В файле Игрока перейдите к `InventoryInfo`.
2.  Найдите пустой слот или существующий ненужный предмет.
3.  Измените `StaticID` на ID желаемого предмета (например, `Accessory_HeatResist_3`).
4.  Отрегулируйте `StackCount`.

### Поля игрока (если доступны)
В файле Игрока `PlayerCharacterMakeData`:
*   `StatusPoint`: Нераспределенные очки характеристик.
*   `TechnologyPoint`: Очки для разблокировки рецептов.

## Шаг 4: Скачать и заменить

1.  Нажимайте **Скачать** только если редактор показывает совместимый режим редактирования.
2.  Убедитесь, что имя файла **точно совпадает** с оригиналом (`Level.sav` или ID игрока).
3.  Заменяйте файл только после проверки резервной копии.
4.  Если редактор работает в режиме только чтения, используйте специализированный инструмент для Palworld.

## Частые вопросы

**В: Работает ли это для выделенных серверов?**
О: Если вы администратор и у вас есть FTP-доступ к файлам сервера (`/Pal/Saved/SaveGames/0/`), да. Остановите сервер, скачайте, отредактируйте, загрузите обратно и перезапустите.

**В: Могу ли я перенести персонажа в другой мир?**
О: Это сложно. Требуется копирование записи игрока внутри `Level.sav` из одного файла в другой и переназначение GUID игрока. Существуют скрипты Python специально для этого ("Palworld Character Transfer"), которые лучше подходят, чем ручное редактирование.

**В: Мой файл слишком большой?**
О: `Level.sav` может стать очень большим (50МБ+). Наш редактор поддерживает большие файлы, но убедитесь, что у вас стабильное соединение и наберитесь терпения во время анализа.

## Сводка совместимости

| Категория | Типичное расположение | Сложность |
|---|---|---|
| Деньги/Золото | Файл игрока (инвентарь) | Легко* |
| Очки технологий | Файл игрока | Легко* |
| Характеристики Палов (IVs) | Level.sav | Продвинуто* |
| Пассивные навыки Палов | Level.sav | Продвинуто* |
| Материалы базы | Level.sav (Инвентарь контейнеров) | Внушительно |
| Время мира | LevelMeta.sav | Легко |

\*Доступно только в совместимых структурах; в режиме только чтения используйте профильный инструмент.

## Советы для безопасного редактирования

1.  **Редактируйте существующие значения** вместо создания новых структур. Безопаснее превратить 1 дерево в 999 алмазов, чем пытаться вставить новый слот инвентаря с нуля.
2.  **Держите значения в разумных пределах**. Уровень 50 — текущий максимум. Установка 9999 может вызвать ошибки или сброс игрой.
