> **対応状況（2026年2月）：** このPalworld向けフローは**標準GVAS**を優先します。コンテナ化/暗号化された保存は読み取り専用になるか、専用ツールが必要です。

## はじめに

**パルワールド (Palworld)** は、クリーチャー収集、サバイバル、基地建設を独自に組み合わせたゲームで世界中を席巻しています。不具合復旧や進行調整を行いたい場合に向けて、本ガイドでは互換性を優先した確認・編集フローを説明します。

無料オンライン **Palworld セーブエディタ** では、怪しいソフトウェアを入れずにセーブ構造を確認し、互換バリアントでのみ慎重に編集できます。すべての処理はブラウザで行われ、セーブファイルはあなたのコンピュータから離れることはありません。

## セーブファイルの場所

### Windows (Steam)
```
%LocalAppData%\Pal\Saved\SaveGames\<SteamID>\
```

### Windows (Xbox/Game Pass)
```
%LocalAppData%\Packages\PocketpairInc.Palworld_<id>\SystemAppData\wgs\
```

### Steam Deck (Proton)
```
~/.steam/steam/steamapps/compatdata/1623730/pfx/drive_c/users/steamuser/AppData/Local/Pal/Saved/SaveGames/
```

### セーブファイルの構造

セーブフォルダ内には以下のファイルがあります：

| ファイル | 説明 |
|---------|------|
| `Level.sav` | ワールドデータ（基地建造物、野生パルなど） |
| `Players/<ID>.sav` | プレイヤーデータ（ステータス、インベントリ） |
| `LocalData.sav` | ローカル設定 |

**重要**：プレイヤーデータを変更するには、`Players` フォルダ内のファイルを編集します。

## ステップ 1：セーブをバックアップ

変更を加える前に、**必ずバックアップを作成**してください：

1. セーブフォルダに移動
2. フォルダ全体を安全な場所（デスクトップなど）にコピー
3. 日付を付けてラベル付け（例：`Palworld_Backup_2026年1月`）

## ステップ 2：オンラインエディタにアップロード

1. [Palworld セーブエディタ](/ja/editor/palworld)（Unreal Engine エディタ）を開く
2. プレイヤーの `.sav` ファイルをドラッグ＆ドロップ
3. GVAS パーサーがバイナリデータを処理するのを待つ

## ステップ 3：データを見つけて編集

保存形式やバージョンにより編集可能な項目は異なります。エディタが読み取り専用を示した場合は、専用ツールへ切り替えてください。

解析が完了すると、ゲームデータの JSON ツリーが表示されます。以下は互換セーブで利用できる可能性がある項目です：

### ゴールド/お金を編集
以下の名前のプロパティを探します：
- `Money`
- `Gold`
- `Currency`

該当フィールドが存在する場合のみ、少しずつ変更して都度ゲーム内で確認してください。

### パルのステータス調整（露出時）
`CharacterSaveParameterMap` に移動してパルを見つけます：
- **レベル**：パルのレベルを調整
- **ステータス**：HP、攻撃力、防御力を微調整
- **パッシブスキル**：受動的能力を確認/調整
- **アクティブスキル**：スロット情報を確認/調整

### 互換性サマリー

| カテゴリ | 互換セーブでの一般的な可用性 |
|---------|-----------------------------|
| **お金** | 通貨フィールドは調整できることが多い |
| **パル** | 一部のレベル/ステータス/スキルが露出する場合がある |
| **インベントリ** | 構造確認は可能、編集可否は構造次第 |
| **プレイヤー** | 一部の進行項目のみ調整可能な場合がある |
| **基地** | 主に閲覧向け、編集は限定的 |

## よくある質問

### マルチプレイヤー/専用サーバーで機能しますか？

**シングルプレイヤー** および **Co-op（ホストとして）**：はい、ローカルセーブファイルを編集できます。

**専用サーバー**：セーブはサーバー側に保存されています。変更するにはサーバーへのアクセスが必要です。

### セーブ編集で BAN されますか？

Palworld のシングルプレイヤー/Co-op にはアンチチートがありません。ただし、専用サーバーでは、管理者がチート禁止ルールを持っている場合があります。
